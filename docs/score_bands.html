The resampling unit differs by domain, deliberately.

Synthetic trials are independent draws from the generator, so the interval comes from an i.i.d. bootstrap over trials. Organic trials cluster within participant, so participants are resampled instead — treating them as independent would make those bands far too narrow. Band width therefore tracks participant count, which is very uneven: whacamole has 176 test participants, crank has 5, pointing has 2.
